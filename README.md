# ⛱️ Travel Buddy

**Travel Buddy** is a modern, interactive web application designed to help travelers explore top destinations across India. Users can enter their starting location to discover various Indian states, browse popular cities, view estimated trip budgets and durations, check transportation options, and view destination photo galleries[cite: 1].

---

## ✨ Features

- **Location-Based Trip Planning:** Enter your starting city to calculate personalized route contexts[cite: 1].
- **State & City Exploration:** Multi-step wizard layout allowing users to select states (e.g., Goa, Himachal Pradesh, Rajasthan, Kerala, Maharashtra, etc.) and explore top cities in each state[cite: 1].
- **Detailed City Guides:** Complete details for each destination including description, recommended duration, and estimated budget ranges[cite: 1].
- **Interactive Transport Guide:** Dynamic budget and travel options for **Road**, **Train**, and **Flight** modes powered by jQuery[cite: 1].
- **Rich Media & Visuals:** Embedded background videos for smooth UI transitions alongside image galleries for every featured destination[cite: 1].
- **Responsive Layout:** Built with Bootstrap 5 and customized CSS grid layouts for desktop and mobile devices[cite: 1].

---

## 🛠️ Tech Stack

- **HTML5 & CSS3:** Structural markup with modern CSS Grid, Flexbox, and video overlay effects[cite: 1].
- **JavaScript (ES6):** Dynamic UI rendering, state management, and step navigation[cite: 1].
- **jQuery (3.7.1):** Interactive DOM manipulation and animated slide toggles for transport information[cite: 1].
- **Bootstrap (5.3.2):** Core styling and UI components[cite: 1].
